## What is checked into git

- Custom CSS snapshots from live themes under `wp-content/themes/`
- Theme screenshots where publicly available
- Custom plugin `bds-directory-connect` for Directory home browse/search wiring

## What is NOT in git yet

PHP theme/plugin source is not publicly downloadable from the live servers (WordPress serves HTML or blocks direct PHP access). To complete this depository, upload the local **BrandDad Social** Cursor project (or a WP/SFTP export) into this repo.
